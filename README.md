#Interactive Story Project

This Project is an interactive story called Elysium-9. It was built using Python, Streamlit, and Gemini API

##Overview
Set in the year 2349, you play as a space thief hired to steal the powerful Star Core from NovaCorp's heavily guarded space station, Elysium-9. You must explore seven locations, collect useful items, avoid or fight security robots and guards, and manage your health and security levels. With help from NOVA, a robotic AI narrator, your mission is to steal the Star Core and escape before you are captured.
